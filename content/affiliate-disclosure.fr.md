Certains liens de ce site sont des liens d'affiliation. Si vous souscrivez un service via l'un
d'eux, le fournisseur verse une commission à ce site. Le prix reste le même pour vous.

Les règles que je respecte :

- Un fournisseur n'est recommandé que s'il héberge quelque chose de ma production, sinon le texte
  dit clairement que rien n'a été testé.
- Les liens affiliés portent `rel="sponsored nofollow"` et passent par `/go/<fournisseur>/` : la
  destination est visible avant le clic.
- Les points négatifs restent dans l'article. Une commission n'efface aucun défaut.
- Aucun placement payant, aucun article invité, aucune insertion de liens.

Programmes partenaires actuels : Infomaniak, Proton, DigitalOcean, Vultr, Hetzner. La liste change
avec le stack.
